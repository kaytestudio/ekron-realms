# v0.48 — новая карта в основной нативной игре

Источник пользователя: https://github.com/nbnbnjkii/ekron/blob/f2d65a465935ba7312491d0de8cb764e57db06f4/3d-destroyed-city-map.zip
Git blob архива: e54ccc6d53255e09a7d21366bb0e0f3647069011.

Архив содержит Three.js/TypeScript-генератор, а не готовую GLB. Его `generateCity.ts` и `textures.ts` сохранены без изменений в `tools/city-map/src/city`. Экспорт выполнен офлайн через Three.js GLTFExporter. В приложение не добавлены JS, браузер или WebView.

Настройки мобильного варианта исходника: seed 2025, 12×12 кварталов, разрушение 65%. Размер 998 м, 578 зданий, 1634 дополнительных объекта, 327148 экспортированных треугольников. GLB содержит встроенную текстуру фасадов и COLOR_0. Загрузчик/шейдер теперь сохраняют вершинные цвета (старые модели по умолчанию белые). Огонь экспортирован как статическая геометрия, без браузерных частиц/анимации/погодных эффектов.

`destroyed_city.glb` заменяет старую карту в APK. Старая GLB перемещена исключительно в `tests/native/fixtures` для регрессионных тестов и не упаковывается в приложение. Старые надписи, привязанные к координатам прежней улицы, не рисуются. Модели машины/дрона/пульта, каталог, управление и механика основной игры сохранены.

Исходный масштаб сохранён, дальняя плоскость камеры увеличена до 2000 м. Поиск восстановления/парковки использует локальное окно 96×96 м на больших картах, а не сетку всего километрового уровня. Физические треугольники и границы охватывают карту целиком. Сохранение новой карты: `destroyed-city-2025-v1.txt`; старое сохранение не переносится.

Воспроизведение экспорта: Node 22, `cd tools/city-map && npm ci && npm run export`. Шум текстуры дополнительно зафиксирован seed, геометрический генератор не менялся. Права на пользовательский архив отдельно не проверялись.

Автотест `destroyed_city_test.cpp`: декодирование новой GLB, текстура не пустая, цвета, размеры, коллизии, старт/парковка и поиск вдали от начала координат. CI дополнительно проверяет отсутствие старой карты в APK. Это не тест запуска на Android-устройстве; FPS/память на телефоне не измерены.
