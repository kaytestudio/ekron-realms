# ЭКРОН — нативная Android-песочница

Основной Android-проект для этих изменений: **`sys/android`**. Дубликаты в `engine/android` и `engine/sys/android` не обновлялись.

Приложение использует существующий GameActivity и библиотеку `librealms.so`. Демонстрационный рендерер с картинкой робота заменён кварталом на **C++ / OpenGL ES 3**. WebView, сайта, JavaScript, npm и подключения к серверу в APK нет. Настольный Pascal-код пока не объединён с Android-рендерером.

## Что добавлено в нативный код

- Квартал из восьми домов, часть повреждена; входы с настоящими проёмами, простая обстановка, завалы, машины.
- Вид от первого лица. Касание и перетаскивание слева — ходьба, справа — поворот камеры. Два пальца поддерживаются одновременно.
- Коллизии со стенами, мебелью и своими постройками.
- Русские Android-кнопки строительства поверх нативной поверхности.
- «Строить» включает предпросмотр; кнопка с названием переключает предметы, «Повернуть» меняет ориентацию на 90°, «Поставить» размещает предмет.
- Каталог: стена, пол, окно, дверь, стол, стул, шкаф, диван.
- Предпросмотр зелёный при допустимом размещении, красный при пересечении или выходе за границы. «Готово» отменяет предпросмотр.
- «Убрать своё» удаляет ближайший свой объект по горизонтальному направлению взгляда в пределах 9 м.
- До 500 объектов. Автосохранение после изменения в `files/sandbox-v1.txt`, запись через временный файл и rename. Загрузка при старте. Сохранения браузерного прототипа сюда не переносятся.
- При потере фокуса движение сбрасывается, игровой цикл перестаёт активно рисовать в фоне.
- Добавлены отсутствовавшие в Git AndroidManifest и тема приложения; горизонтальный полноэкранный режим.
- Заданий, целей и сюжетных маркеров нет.

## Сборка APK

Нужны JDK 17, Android SDK 34 / Build Tools 34.0.0, NDK 26.1.10909125, CMake 3.22.1, доступ к Google Maven и Gradle.

```sh
cd sys/android
# При необходимости укажите путь sdk.dir в local.properties (не коммитить).
./gradlew :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Debug-пакет подписывается отладочным ключом. Для обновления уже установленного APK нужен тот же ключ подписи; удаление приложения очищает постройки.

В `.github/workflows/android-sandbox.yml` добавлена сборка на push/PR и ручной запуск. При успешном выполнении артефакт `ekron-native-sandbox-debug` содержит APK. Наличие workflow не означает, что сборка уже прошла.

## Проверки и ограничения

Проверка логики без Android SDK:

```sh
# Из корня репозитория
g++ -std=c++17 -Wall -Wextra -Werror -pedantic tests/native/sandbox_world_test.cpp -o /tmp/ekron-world-test
/tmp/ekron-world-test
```

Проверяются размещение, запрет пересечений, поворот габаритов, удаление, сохранение/загрузка, отклонение повреждённых сохранений, вход в дом и столкновение со стеной.

В среде разработки нет Java/SDK/NDK: тесты логики выполнены, но компиляция Android JNI/GL-кода, установка APK, визуальный результат и мультитач на устройстве локально не проверены.

Графика — цветная низкополигональная заготовка, не детализация концепта. Один ограниченный квартал; нет стриминга мира, боя, прыжка, разрушаемости или мультиплеера. Строительство только на земле, без этажей и соединения элементов; коллизии двумерные. Окно и дверь пока декоративные, не открываются. Удаление использует горизонтальный луч, не учитывает высоту прицела и перекрытие стеной. Уведомления об ошибке сохранения пока только в logcat. Перед выпуском нужны доработка выбора объектов, оптимизация мешей, реальные модели/текстуры и проверка на телефоне.
