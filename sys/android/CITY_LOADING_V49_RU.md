# v0.49 — загрузка новой карты

В v0.48 индикатор 12% охватывал целиком чтение GLB, преобразование почти миллиона вершин, поиск старта и построение BVH. Нативный debug APK при этом собирался без оптимизации C++, хотя именно debug APK раздаётся для игры. Особенно дорогим был поиск старта: каждая ячейка сетки проверялась против всех локальных стен, а поиск точки с запасом повторял проверки даже для заведомо худших кандидатов.

Исправления:
- Растеризация препятствий только по пересекающим их ячейкам; точные проверки стен/коробок сохранены.
- Проверка запаса свободного места только для кандидатов, которые могут улучшить текущий результат.
- Нативный Debug использует -O2 с сохранением символов; Java/Kotlin-режим приложения остаётся debug.
- GLB упаковываются без ZIP-сжатия для устранения распаковки больших моделей при чтении.
- Проценты обновляются по реальным этапам чтения/геометрии/поиска старта/коллизий, подпись явно указывает новую карту.
- Ошибка загрузки города теперь выводит накопленную диагностику в logcat / Ekron.

Новая карта не заменялась и не уменьшалась. Контроль наличия `assets/models/destroyed_city.glb` и отсутствия старой карты в APK остаётся в CI. Регрессионный тест сравнивает результат новой растеризации с прежним полным перебором на тестовых сценах, проверяет этапы прогресса и загружает полную пользовательскую карту. Проверки на хосте и сборка не являются запуском на телефоне.
