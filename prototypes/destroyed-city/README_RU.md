# Отдельный просмотрщик процедурного города

Основная игра `sys/android` и её модели/текстуры не меняются.

## APK: Kotlin + LibGDX
`libgdx/` — самостоятельный Gradle-проект с модулями `core` и стандартным `android` backend LibGDX **1.12.1**, Kotlin 1.9, Android SDK 34, Java 17, ARM64. Другое applicationId: `com.ekron.citypreview`, можно установить рядом с основной игрой.

`core/src/main/kotlin/com/example/city/DestroyedCity.kt` **побайтно совпадает** с последним приложенным `aiprovider-code (1).txt`; оригинал также сохранён в `originals`. SHA256: `837baaa057ea271b020ed97992bd81b84f2733f3ec9dff88d78f94dfb02907aa`. Второе вложение с зависимостями сохранено отдельно. Никаких GLB, внешних моделей или текстур мира: исходный генератор создаёт свои кубы и цилиндры.

Просмотрщик вызывает `generate(citySize=12, blockSize=42f, roadWidth=10f, destruction=.5f)`. `Max Floors` и `Rubble Amount` из первоначального Unity-кода отсутствуют в новом Kotlin-коде: количество этажей 2..9 и мусор остаются именно как прислано. Seed 1642 и порядок случайных вызовов не менялись. Это мир из **нового Kotlin-вложения**, а не обещание совпадения с прежним C#.

### Полёт
Слева — перемещение по горизонтали, справа — обзор; центральные ↑/↓ — высота. «На старт» возвращает обзорную камеру. Свободный полёт без коллизий позволяет осматривать карту со всех сторон. При сворачивании ввод сбрасывается. Исходный город генерируется один раз на GL-потоке, загрузочный экран Android остаётся отзывчивым; после генерации появляется управление. Большая генерация может потребовать много времени/памяти.

### Сборка
```sh
cd prototypes/destroyed-city/libgdx
./gradlew :core:test :android:assembleDebug
```
Нужны Java 17, Android SDK 34/Build Tools 34.0.0 и доступ к Gradle/Google Maven/Maven Central. APK: `android/build/outputs/apk/debug/android-debug.apk`.

GitHub Actions: `.github/workflows/destroyed-city-libgdx.yml`, артефакт `destroyed-city-libgdx-debug`. Проверки: исходник совпадает с сохранённым оригиналом, JVM-тесты ввода, компиляция APK и наличие ARM64 `libgdx.so`. Сборка/JVM-тесты НЕ подтверждают запуск графики на телефоне. Android-устройство/эмулятор здесь не использовались.

### Ограничения исходника
Генератор создаёт отдельный Model/Mesh для каждого примитива и рендерит все объекты без чанков/LOD/culling. Для сохранения точного кода это не оптимизировалось. Нельзя обещать стабильные FPS, отсутствие OOM на слабых устройствах или быстрый старт. В режиме повторной генерации оригинальный Random не переинициализируется; просмотрщик не вызывает повторную генерацию.

## Сохранённый Unity-вариант
`Unity/` — подготовленные файлы для Unity 2022.3 URP и первый C#-исходник без изменений. К сборке LibGDX они отношения не имеют. Unity Editor/лицензии в этой среде нет, Unity-проект не запускался и не является источником данного APK. Выбранный пользователем активный вариант — **LibGDX**.
